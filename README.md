Este aplicativo é a Tela Principal de um diário pessoal com a temática mística de observação do céu e registro de estrelas e constelações, desenvolvido em React Native com uma paleta de cores baseada em tons de roxo profundo e lilás.

O código reúne de forma integrada todos os componentes exigidos pelo Módulo 2:

SafeAreaView e StatusBar: Garantem que o conteúdo respeite os limites seguros da tela do celular, combinando com o tema escuro noturno.

ScrollView: Torna a tela rolável, permitindo navegar fluentemente entre o formulário de cadastro, o banner temático e a lista de registros.

View e Text: Estruturam os blocos de cartões, títulos, subtítulos e as datas das observações.

TextInput: Permite que o usuário digite o nome da estrela/constelação observada e adicione anotações/sentimentos sobre o céu.

Pressable: Funciona como um botão interativo estilizado que pega o que foi digitado nos inputs e adiciona em tempo real na lista de registros recentes do usuário.

Image: Exibe um banner visual ilustrativo no meio da página para ambientar o tema do aplicativo.
